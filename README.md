# Advent of Code 2025 em Go

Soluções para os 12 dias publicados no Advent of Code 2025. Cada dia é um
programa independente e contém seus próprios testes.

```sh
go test ./...
make run
go run ./day01
go run ./day02
# ...
go run ./day12
```

Para usar outro arquivo de entrada, passe seu caminho como primeiro argumento:

```sh
go run ./day05 caminho/para/input.txt
```

Os arquivos `dayXX/input.txt` foram obtidos da conta do usuário e são ignorados
pelo Git, conforme a recomendação do Advent of Code de não publicar inputs.

O dia 12 encerra a edição de 2025 e possui somente uma parte oficial.
